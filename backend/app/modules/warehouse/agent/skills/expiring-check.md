name: expiring-check
description: 复验期预警。当用户问哪些物料快到复验期/有效期、要盘临期物料时加载。
---
## 步骤
1. **查临期库存**：调用 `query_stock(expiring_days=N)`；N 为用户关注的天数，用户未说明时默认 30（「快到复验期」= 未来 30 天内到期）。
2. **排序**：把返回批次按「有效期至/复验期至」升序排列（最紧急的排最前）；结果为空时如实说明「N 天内没有到期的批次」并建议放宽天数，然后结束。
3. **标注紧急度**：按剩余天数（到期日 − 今天）标注：剩余 <7 天 = 🔴 紧急；7~15 天 = 🟠 预警；>15 天 = 🟡 关注。剩余天数按今天推算，并在清单末尾注明推算口径。
4. **输出预警清单**：按「输出格式」生成清单卡片；total 超过返回明细条数时注明「共 X 条，仅展示前 10 条，可加关键词缩小范围」。
5. **可选发送**（仅在用户确认后）：用户要求发送给指定人/群且提供了确切 `user:<open_id>` / `group:<chat_id>` 时，调用 `send_card` 发送预警清单（确认门：预览卡片需发起人点「确认发送」才会真正发出）；用户只给姓名/群名而 ID 不可得时先询问，禁止猜测。

## 输出格式
预警清单按以下 markdown 结构输出：

### 复验期预警（未来 N 天）

| 紧急度 | 物料 | 批号 | 剩余天数 | 数量 | 有效期至 |
|---|---|---|---|---|---|
| 🔴 紧急 | … | … | X 天 | …（含单位） | YYYY-MM-DD |

末尾注明：剩余天数按今天（YYYY-MM-DD）推算；所有数字/批号/日期来自 query_stock 工具结果，禁止编造。
