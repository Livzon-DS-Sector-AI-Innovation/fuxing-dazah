前端（首次部署）
pnpm build
docker build --platform linux/amd64 -t dazah-frontend:latest .
docker save dazah-frontend:latest | ssh -p 3303 root@192.168.3.100 'docker load'
rsync -avz -e "ssh -p 3303" docker-compose.yml root@192.168.3.100:~/frontend/
rsync -avz -e "ssh -p 3303" .next/standalone/.next/ root@192.168.3.100:~/frontend/.next/
rsync -avz -e "ssh -p 3303" .next/static/ root@192.168.3.100:~/frontend/.next/static/
rsync -avz -e "ssh -p 3303" public/ root@192.168.3.100:~/frontend/public/
ssh -p 3303 root@192.168.3.100 "cd ~/frontend && docker compose up -d"

前端（src 变更，高频）
pnpm build
rsync -avz --delete -e "ssh -p 3303" .next/standalone/.next/ root@192.168.3.100:~/frontend/.next/
rsync -avz --delete -e "ssh -p 3303" .next/static/ root@192.168.3.100:~/frontend/.next/static/
rsync -avz --delete -e "ssh -p 3303" public/ root@192.168.3.100:~/frontend/public/
ssh -p 3303 root@192.168.3.100 "cd ~/frontend && docker compose restart frontend"

前端（依赖或 next.config.ts 变更，低频）
与首次部署相同，需要 rebuild 镜像 + rsync .next/

后端
服务端更新代码
如果有变更项目依赖或数据库，执行
docker compose --profile app down
docker compose --profile app up -d --build
只是app代码更新，执行
docker compose restart app
重载环境变量，执行
docker compose --profile app up -d --force-recreate
