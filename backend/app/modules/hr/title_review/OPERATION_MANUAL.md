# 职称评审系统 v3 — 上线前置清单与 HR 操作手册

> v3 最终架构：**申报走飞书审批**（部门负责人→HR 两道，飞书原生，零应用权限）→ 审批通过
> 自动写入申报表 → 系统 5 分钟同步进内网 → **评委登录内网系统投票**（匿名编号）→
> 票数判定（同意÷(同意+不同意)≥2/3）→ 飞书卡片通知申报人。系统内不再有初审/终审环节。

## 二、HR 操作手册（一个年度活动的完整流程）

### 第 1 步：新建活动（内网「人事管理 → 职称评审」）

1. 「活动管理」→「新建活动」：名称（2026年度技术职级评定）、通过比例（默认 2/3）、截止时间、粘贴飞书 `app_token=HKb0bhufoab2wwsblj1c9qxgnPI`、申报表 `tblq63r6qdlICQaJ`（投票表不再需要，可留空）。
2. **职级组标准**：默认带出 9 个职级组，编辑各组评审标准文本。
3. 点「绑定表格」校验 → 「开启申报」。

### 第 2 步：配置部门评审组

活动管理页 →「部门评审组」：按部门录入**职级评定小组**（默认评委名单）。（部门负责人/分管领导已由飞书审批承担，无需在此录入。）

### 第 3 步：员工申报（飞书审批，外网可用）

员工在飞书审批发起「职称申报审批」→ **部门负责人审批 → 陈肖潇复核** → 审批通过后自动化写入申报表 → 系统 5 分钟内同步进内网（自动校验姓名工号）。

### 第 4 步：评委分配（自动按部门，无需逐个指定）

- 活动点「开始评审」时，系统**自动按部门分配评委**：每个部门的申报自动分给该部门评审组的评定小组成员，并发送飞书提醒卡。
- 迟交的申报：进入系统时自动流转并分配（活动评审期内）。
- 特殊调整：HR 可在「申报与评审」页对单个申报人「指定评委」增减成员、调整角色。

### 第 5 步：评委投票（内网系统，无需飞书表格）

评委登录内网系统 → 菜单「**职称评审投票**」（需 `hr:title:judge` 权限）→ 查看申报材料（自我评价/业绩/附件）→ 提交：**投票结果（同意/不同意/弃权）+ 综合等级 + 7 维评价 + 意见**。
- 评委之间互不可见（匿名编号 P1/P2… + 权限隔离：只能看自己的任务）
- **全部评委投完 → 系统自动判定**：同意÷(同意+不同意) ≥ 通过比例；弃权不计分母
- 票数与结果自动回写飞书申报表（同意/不同意/弃权票数、附件4评审结果、综合意见）
- 需要提前截止：HR 在申报列表点「按当前票数判定」

### 第 6 步：结果通知与归档

- 判定完成自动发飞书卡片给申报人（只含结果，不透露评委）
- HR 在「评审结果」页查看：票数、比例、各评委投票明细（`hr:title:scores:read` 权限）
- 完成后「结束」活动，数据冻结归档可审计

### 兜底能力

- 手动「同步」按钮 + 每 5 分钟自动对账（事件丢失自动补齐）
- 评委改票 → 自动重新判定；已判定不重开
- 未投票评委可撤换，已投票不可撤换

## 三、权限规划（仅赋权人员可进入）

系统入口控制（前端+后端双重拦截）：
- **菜单/页面级**：无职称评审权限的人员看不到入口；直接输入网址会显示"无权限访问"提示
- **API 级**：所有接口均校验权限码，无权限一律 403

| 角色 | 授予权限码 | 能做什么 |
|---|---|---|
| HR 负责人 | `hr:title:read` + `hr:title:manage` + `hr:title:scores:read` | 全部：活动配置、部门评审组、评委调整、判定、查看投票明细 |
| HR 专员 | `hr:title:read` | 查看申报与进度（看不到投票明细与分数） |
| 评委 | `hr:title:judge`（仅此一个） | 只能进入「职称评审投票」页面，只看到自己被分配的投票任务；看不到管理页与其他申报 |
| 其他人员 | 不授予任何 hr:title:* 权限 | 完全不可见、不可访问 |

配置方法：内网系统「权限管理」页 → 给对应角色勾选上述权限码（评委角色建议单独建"职称评委"角色，批量赋给评定小组成员）。

## 四、开发维护参考

- 申报表回写列：同意票数/不同意票数/弃权票数（number）、附件4评审结果（select：通过(三分之二以上同意)/不通过/待评审）、附件4评审综合意见（text）
- 评价项固定 7 个：本职工作完成评价/工作思想表现评价/组织协调能力评价/开拓创新能力评价/科技项目成果评价/培养指导人员评价/论文专利著作评价
- 申报同步字段映射常量：`service.py` 的 APPLY_SELF_EVAL_FIELDS / APPLY_WORK_FIELDS / APPLY_ATTACHMENT_FIELDS
- 审批定义 approval_code：`D6E3CFE6-49E4-4700-9965-F7E8EF0993B0`
- 审批同步（可选启用）：活动配置填 approval_code 后，系统每 5 分钟拉取已通过审批实例直接落库（需应用有 approval:approval:readonly）；未启用时依赖"审批自动化写申报表 + 表格对账"链路
