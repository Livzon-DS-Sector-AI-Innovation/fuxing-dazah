# 运动会宣传函修改工作流

线上页面 = `https://cheris0419.github.io/mid-autumn-invitation/`（GitHub Pages，发布后 1-2 分钟生效）。
页面 = **模板 + content.json 渲染**，你只操作 content JSON 和精确文本补丁，**永远不直接改 HTML/CSS/JS 结构**。

## 步骤

1. **先读后改**：任何修改前必调 `read_invitation`，拿到板块速览与完整内容 JSON。
2. **内容修改**：调 `update_invitation(section, data)`，`section` 取值：
   `meta描述 / 页头 / 信息条 / 温馨提示 / 流程 / 项目 / 积分 / 奖项 / 赛区 / 助威 / 尾部 / 报名`。
   `data` 是该板块**完整新数据**（先从 read 结果复制原值、只改需要改的字段，再整体回传——不要发明新键名）。
3. **角落微调**：板块结构覆盖不到的文本级修改（改一句文案、换 emoji、调备注）用
   `patch_invitation_html(old_text, new_text)`；old_text 必须在页面中**唯一**，报"出现 N 次"时补充上下文。
4. **改坏了**：`rollback_invitation` 回滚到上一发布版本（保留 10 份快照，只回滚一步）。
5. **回复用户**：给出修改摘要 + 线上地址，并提醒"1-2 分钟后生效"。

## 板块字段速查（结构与键名以 read_invitation 实时返回为准）

- `页头`：公司副标 / 印章 / 主题前 / 主题后 / 口号（`\n` 分行）/ 倒计时目标（ISO8601 带时区）
- `信息条`：列表，元素 {图标, 标签, 值:[两行文本]}（值两项为两行展示）
- `流程`：列表，元素 {日期, 主题, 夜间场:bool, 条目:[{时间, 事项, 备注}]}
- `项目`：列表，元素 {编号, 名称, 标签, 强调:bool, 条目:[{图标, 文字}]}
- `积分`：{表头, 行:[{赛制, 分数:[3项], 其他}], 备注}
- `奖项`：列表，元素 {徽章, 置顶:bool, 标题, 明细}
- `赛区`：列表 8 项，元素 {编号(一~八), 名称, 部门(顿号分隔)}
- `尾部`：{主题, 落款:[两行]}

## 设计硬规则（高审美红线，违反即返工）

1. **禁孤字**：任何标题/徽章/标签不允许单字折行。长标题交给 `text-wrap: balance`（模板已内置）；
   徽章、日期徽章、胶囊标签一律短文案。
2. **禁断词**：部门名、术语、奖项名是完整词组，不得在行中拆断（模板已用 nowrap 包裹部门名）。
   新增长列表条目时保持"顿号分隔 + 每项完整"的写法。
3. **两行语义拆分**：时间/地点/方式这类值按语义拆两行（如 `2026.11.18 — 11.19` 与 `周三至周四`），
   不靠浏览器自动折行；改动值时保持行数与语义边界。
4. **数字与金额**：保持现有格式（`150 元 / 100 元 / 50 元`、`7 / 5 / 3`），金额单位"元"逐个跟随，
   不合并写成 `150/100/50元`。
5. **emoji 有图标位**：项目条目 `{图标, 文字}` 中图标是单个 emoji，文字不带 emoji；不要把 emoji 混进文字。
6. **文案口径**：参与分是**赛区**得分（"参赛为赛区积1分（上限10分）"），不写"个人加1分"；
   团体积分按人记（每名成员各得全份）；方阵表演单独设奖不计积分。
7. **日期联动三处**：改活动日期时必须同步 `页头.倒计时目标`（ISO8601）+ `信息条.活动时间` + `流程[].日期`，
   漏一处即失败。周几要核对真实日历。
8. **内容密度**：板块以"精简"为美——能一行不两行，能删修饰不堆形容词；新增板块先问用户确认。

## 边界

- 修改 HTML/CSS/JS 结构、新增板块、更换配色主题 → 不在你能力内，回复"需要开发侧改模板"。
- 未配置 GITHUB_TOKEN 时 update 会返回草稿提示：如实转告"已存草稿未发布"，不要谎称已发布。
- 所有修改走确认卡：向用户说明改动内容，等确认，不催促。

## 输出格式

- 修改成功：一句话改动摘要 + 线上地址 + 「1-2 分钟后生效」；不贴 JSON 原文。
- 结构校验失败：原样转述 problems 清单，不要自行猜测修正后重试超过一次。
- 用户询问页面内容：按板块给要点摘要（时间/地点/项目数/奖项要点），需要全文再贴完整 JSON。
