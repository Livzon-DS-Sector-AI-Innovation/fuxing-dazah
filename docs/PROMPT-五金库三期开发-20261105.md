  - 通过后销账：FIFO 扣批次 + `scrap` movements（quantity 恒正）+ 单据留档；驳回零动账
  - 前端：reports 页增「报废」Tab（发起/审批/台账）
- **实物照片初筛**（L1 vision，设计 §9.1 二期后按需项）：
  - 新场景 key `hardware_photo_screening` 注册 scenario_registry
  - 入库确认环节（Web+agent 两入口）可附实物照片 → vision 初筛（破损/锈蚀/渗漏/受潮）→ **advisory 标记落 receipt 行**（只标记不拦截不代改——MSDS 模式红线）；checklist 展示初筛结论供仓管员参考

### M8 ERP 导入通道 A 档 + 并存对账（~1-1.5 天，fixture 驱动）

- 前端：reports 页 ERP 对账 Tab 升级（erp_import 单列表+匹配状态+差异清单）；inout 工作台增「ERP 导入」入口

### M9 observe→auto 阶段 1 放权（~0.5-1 天，默认关）

- **direct 类高置信 OCR 直接入账**（设计 §9.3 阶段 1，红线：stocked 类永不自动）：
