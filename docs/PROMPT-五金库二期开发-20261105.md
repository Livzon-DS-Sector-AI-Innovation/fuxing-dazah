## 范围（=设计文档 §十一 二期，不得扩大/缩小）

### M4 盘点 + 退库（~1 天）

- 新表（照 §2.6）+ alembic 迁移（含 downgrade）：`hardware_returns` / `hardware_stocktakes` / `hardware_stocktake_items`
- 盘点闭环：生成盘点单（book 快照自当前批次余额）→ 前端 `/warehouse/hardware/stocktake` 手机实盘直填 → 差异表导出 Excel（编码/名称/账存/实存/差异数/差异金额=unit_price×差异；中文文件名导出参照 safety 先例）→ 差异说明+确认（确认门卡片，**人确认才生效**）→ `stocktake_adjust` movements 入账
- **期初校准链路（P4 收口）**：首次全面盘点=零库存起步后的存量盘盈入账——验收须造「零库存+实物盘盈→确认→ADJ 入账→available 正确」全链
- 退库：退库单（退库人/部门负责人签/仓管员验收，不合格拒退）→ 批次回加（优先回原 lot 增 remaining_quantity，原 lot 不存在则新建 return 来源 lot）→ `return_in` movements；前端入口并入 inout 工作台

### M5 月度采购计划 + 呆滞 + 温湿度（~1-1.5 天）

- 新表+迁移：`hardware_purchase_plans`(+items) / `hardware_env_logs`
- 月度计划：25 日 FIXED_TIME 定时任务（并入 `register_hardware_tasks`）→ 快照（available/部门月需求）→ 生成次月计划**草案**：月采购量=安全库存量+月使用量−25 日实际库存量（P7 公式；月使用量=近月 outbound 流水聚合）；**同月重跑覆盖草案幂等**；前端 `/warehouse/hardware/plans` 草案编辑+导出制度附件 4 表样 Excel（列：序号/物料编码/物资名称/规格型号/单位/数量/月需求合计/安全库存量/当月25日库存量/月度采购量/备注）
- AI 用量注释（L4 决策辅助）：新场景 key `hardware_plan_annotation` 注册 scenario_registry；近 3 月消耗趋势/异常波动 → 落 plan 行 `ai_note` **建议态字段**，人审核采纳，不自动改数量
- 呆滞：季度定时扫描（连续 3 个月无 outbound 的 stocked 物料，按 movements 回算）→ 清单卡片推送（push_center）
- 温湿度：env_logs 录入 API+前端快捷录入 + 每日提醒任务（TaskDefinition）

### M6 superagent 接入 + 报表完善（~1-1.5 天）

- 事件源 `hardware_alert_scan`（Source 注册，照 R1 scan_source 模式）：5 类事件——安全库存击穿 / 呆滞到期 / 紧急 24h 未补单 / OCR 草稿积压（超 N 单可配）/ 审批通过未发料超时；白名单∪闭环去重规则（同事件不重复触发）
- 执行器 3 个（Executor 注册，确定性函数，照 R1 executor 模式）：
