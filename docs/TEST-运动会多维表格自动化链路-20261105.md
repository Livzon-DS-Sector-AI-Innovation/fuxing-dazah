## 二、平台边界（实测确认，非配置问题）

1. **`ChangeRecordTrigger` / `AddRecordTrigger` 在本 base 编译失败**（`Watch Field is empty`，watched_field_name / watched_field_id / 去条件 / 去控制列表四种形态穷举无效）→ 采用 `SetRecordTrigger`（仅监听修改）版本。
2. **实测补充**：`SetRecordTrigger` 对"新建记录的字段初始化"同样会触发（延迟数分钟）——即"新建即已确认"场景实际也被覆盖（测试 4），仅存在执行延迟。
3. **`Loop` 数据源仅支持 `FindRecordAction.fieldRecords`**，无法遍历人员数组字段（`item` 路径不存在）→ 团体赛按成员拆行无法在多维表格自动化内实现，保留边栏插件「立即同步」一键拆行。

## 三、遗留事项

1. **AI创新部赛区归属**：许康福（AI创新部）积分行「所属赛区」为空——AI创新部不在策划案八赛区映射中，待组委会拍板后补一行公式。
2. **调试字段**：报名表的 调试A/B/D 为建表期探针残留，可手动删除。
3. **报名状态口径提醒**：报名组确认操作是「改字段值」而非「新建已确认记录」时触发最可靠；如发现新建即确认的报名未被同步，打开插件点一次「立即同步」即可补齐。
