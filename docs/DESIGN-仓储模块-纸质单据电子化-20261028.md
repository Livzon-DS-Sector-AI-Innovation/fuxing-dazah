## 〇、通用机制（各单据不再重复）

**两类表单**
- **Bitable 表单视图**（免审单据用）：在目标台账上新建表单视图，拖入表单字段、设必填，分享链接发到仓库群（组织内可填）。提交即生成一条台账记录。
- **飞书审批表单**（审批单据用）：在审批管理后台建审批定义，表单含业务字段+手写签名控件（申请人用），审批人手机审批即签名。

**机器人后处理**（轮询发现新记录/新实例，按修改时间增量，复用现有镜像轮询模式）
- 表单新记录且单据号为空 → 生成单号、回填操作人（取表单提交人）与日期、主数据对齐（物料代码等公式列自动带出）；
- 审批实例通过 → 回写审批字段组、执行生效动作（出账/调整库存）；
- 审批驳回 → 卡片通知发起人，改后可重提（单号不变）。

**审批字段组**（需审批的台账统一加三列）：审批状态（单选：待审批/已通过/已驳回）、审批完成时间（日期）、审批实例链接（文本）。

| 字段 | 类型 | 必填 | 说明 |

| 物料名称 | 文本 | ✅ | 写「物料名称(API)」列，机器人对齐主数据带出代码/级别 |
| 级别/型号 | 文本 | 选填 | 写「级别/型号(API)」列 |
| 物料批号 | 文本 | ✅ | |
| 厂家批号 | 文本 | 选填 | |
| 入库数量 | 数字 | ✅ | |
| 单位 | 单选 | ✅ | Kg/瓶/L/桶… |
| 件数 | 数字 | 选填 | |
| 包装规格 | 单选 | 选填 | |
| 车牌 | 文本 | 选填 | |
| 到货时间段 | 文本 | 选填 | |
| 合同编号或订单号 | 文本 | 选填 | |

- **如何填写**：仓管员收货，**用纸质送货单核对实物**（纸单用完随货处置）→ 手机飞书打开表单链接（固定在仓库群公告，或对机器人发「入库」取链接）→ 填写提交。
- **提交后**：记录落台账 → 机器人补：单号 RK、入库日期=当天、入库仓管员=表单提交人、到货情况=到货物料（默认）→ 自动推 QC 请验卡（复用现有链路）。完成，无审批。

## 二、成品入库单（免审）

- **表单形式**：Bitable 表单视图「**成品入库单**」（**已存在**），挂在**成品入库台账**（成品 Base，tblf2WmK787dA91b）。
- **表单字段**：品名（文本✅）、生产批号（✅）、数量（数字✅）、单位（单选✅）、生产车间（单选✅）、生产日期（日期，选填）、质量状态（单选：合格/待检，✅）、随车批次标识（文本，选填，见下）、备注（选填）。
- **多行明细**：一车多品种时逐行提交表单，同一车的各行填同一个「随车批次标识」，机器人按标识聚合生成同一个 FK 单号；单品一行的可不填标识。
- **如何填写**：仓管员手机打开表单链接（仓库群固定）逐行填写；也可继续用对话登记（机器人多行收集，已支持）。
- **提交后**：机器人补单号 FK、登记人=提交人、入库日期。无审批。

## 三、GMP 出库单（一级审批）

- **登记**：仓管员对机器人对话登记（已有场景），或表单视图「**质量出库**」（**已存在**）挂**GMP物料出库总账**（GMP Base，tblhnP8QqJW7qyp1）：物料批号（✅）、数量（✅）、单位（✅）、生产批号（✅）、领用部门（单选✅）、用途（文本，选填）、备注。
- **提交后**：记录落台账（审批状态=待审批）→ 机器人创建飞书审批实例「GMP出库审批」（审批表单字段：单号/物料/批号/数量/领用部门/用途，由机器人预填）→ **仓库主管**手机审批签名 → 通过：回写审批字段组、出账生效；驳回：机器人卡片通知仓管员。
- **落表**：单号 GM、创建人=登记仓管员。

## 四、领料单（两级审批，车间自助）

- **表单形式**：飞书审批定义「**领料申请**」（审批中心原生表单，不用 Bitable 表单——需要手写签名）。
- **审批表单字段**：物料名称（文本✅）、数量（数字✅）、单位（单选✅）、需用日期（日期✅）、用途说明（文本，选填）、**手写签名**（签名控件✅）。发起人所在车间由组织架构自动带出，写入领用部门。
- **如何发起**：车间人员手机飞书「审批」→ 发起「领料申请」填写+手写签名；或对仓库机器人发「领料」取发起链接。
- **审批链**：车间主管 → 仓管员。仓管员节点机器人先发一张先进先出批次建议卡（按 QA 放行+入库时间升序），仓管员参考后在审批里签名。
- **通过后**：机器人写**物料出库总账**（原辅料 Base，tblGF4fOKUoaGF4v）：领用部门=发起人部门、领用类型=生产使用（按表单用途判断）、物料批号=FIFO 建议批次、领用日期=审批通过日、单号 LL、出库人(API)=仓管审批节点人、审批字段组。库存扣减。驳回退回车间改后重发。

## 五、成品出库单（一级审批）

- **登记**：仓管员对话登记+快递号（已有），或表单视图「**成品出库单**」（**已存在**）挂**成品出库台账**（成品 Base，tbl7Xg48GFstaPQ5）：品名（✅）、批号（✅）、数量（✅）、收货方（✅）、快递号（文本，写「快递号(API)」列）。
- **提交后**：落台账（待审批）→ 机器人创建审批实例「成品出库审批」（预填单号/品名/批号/数量/收货方）→ **产销主管**审批签名 → 通过出账并自动推快递发货通知卡（已有）；驳回通知仓管员。
- **落表**：单号 CK、出库人(API)=登记仓管员。

## 六、请验单（系统单据，无表单）

- 入库单落账后机器人自动推**到货请验卡**到 QC 群（已有链路）：卡上带 RK 单号、物料/批号/供应商、送货单照片链接（如有）——**这张卡就是请验单，不再有纸质**。
- QC 出报、QA 放行：现有确认卡签名回写物料入库总账的 QC/QA 字段组（出报人/放行人/时间），维持。

## 七、盘点单（一级审批，手机直填）

- **多维表格**：原辅料 Base 新建**盘点明细表**，字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| 盘点单号 | 文本 | ST 号，机器人写 |
| 库位 | 单选 | 贮存点选项与入库总账一致 |
| 物料代码/物料名称/批号 | 文本 | 机器人预填 |
| 账面数量 | 数字 | 机器人按库存快照预填 |
| 实盘数量 | 数字 | **仓管员手填** |
| 差异 | 公式 | 实盘-账面，自动算 |
| 状态 | 单选 | 待盘点/已填/已审批 |
| 盘点人 | 人员 | 机器人回填 |
| 审批完成时间 | 日期 | 机器人回填 |
| 备注 | 文本 | |

- **流程**：仓管员对机器人说「开始盘点（全库/某库位）」→ 机器人按**物料库存明细总表**快照批量写入明细行（账面预填、状态=待盘点）→ 往仓库群发该盘点单的表格视图链接（按单号筛选）→ 仓管员手机打开**直接在表格里逐行填实盘数量**（不用表单，表格视图手机可编辑）→ 全部填完（机器人轮询发现）→ 机器人汇总差异，创建审批实例「盘点审批」（预填盘点号/范围/差异行数/明细表链接）→ **仓库主管**审批签名 → 通过：明细表状态=已审批、生成 ADJ 调整流水、**回写物料库存明细总表数量**（消灭本地/飞书两本账）→ 差异清单进次日晨报。
- 一期覆盖原辅料库存；成品盘点如需要，复制同构表到成品 Base。

## 八、退货/不合格处理单（维持现状+补签名）
