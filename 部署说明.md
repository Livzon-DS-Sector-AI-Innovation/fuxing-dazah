前端
pnpm build
docker build --platform linux/amd64 -t dazah-frontend:latest .
docker save dazah-frontend:latest | ssh -p 3303 root@192.168.3.100 'docker load'
rsync -avz -e "ssh -p 3303" docker-compose.yml root@192.168.3.100:~/frontend/
ssh -p 3303 root@192.168.3.100 "cd ~/frontend && docker compose up -d"
docker compose down && docker compose up -d

后端

服务端更新代码
如果有变更项目依赖或数据库，执行
docker compose --profile app down
docker compose --profile app up -d --build
只是app代码更新，执行
docker compose restart app
重载环境变量，执行
docker compose --profile app up -d --force-recreate
