## 0. 一图看懂数据流

```
员工上报 → Bitable 隐患台账（主表）
   ①轮 AI识别（既有）→ 写回 分类/级别/类别（AI）+判定依据…
   ⑤轮 AI评分（新增）→ 判据: 分类（AI）已填 且 评分结果为空 且 检查日期∈回填窗口
        纯文本调用（无图）: 描述+①识别结论 → AI 选 L/E/C/X 档位 + H/M/L + 重大判定
        代码算: D=L×E×C×X → 写回 2 列: 评分结果(数字) + 评分说明(文本)
查询面: HazardView 增 2 字段 → 台账页直读透传 → 前端「风险分」列
```

## 1. 用户侧前置（唯一手工动作）

在飞书隐患主表（`hazard_direct` 所指台账）加 2 列：

| 列名 | 类型 | 选项/格式 | 说明 |
|---|---|---|---|
| **评分结果** | 数字 | 保留 1 位小数，允许输入小数 | D 值；清空即触发⑤轮重评 |
| **评分说明** | 多行文本 | — | 固定格式见 §4.4 |

> 列名即代码常量，建列后必须与 §3.2 `F_SCORE/F_SCORING_NOTE` 逐字一致（含括号全半角）。不必预建数字格式约束，代码写入 `round(D,1)`。

## 2. ⭐ 新模块 `app/modules/safety/ai_hazard_scoring/`

对标 `ai_urs_review/` 与 `ai_rectification_review/` 的四件套 + 独立 tests。**AI 只选档位，总分/门槛/资格全部代码算。**

### 2.1 `schemas.py`

```python
# —— 档位枚举（枚举值=制度分值，唯一权威；label=制度中文档位，AI 输出中文档位由 rules 映射）——
class LikelihoodTier(StrEnum):      # L 造成事故的可能性
    VERY_LIKELY = "2.0"      # 非常可能
    LIKELY = "1.5"           # 可能
    UNLIKELY = "1.0"         # 可能性小
class ExposureTier(StrEnum):        # E 接触频率
    CONTINUOUS = "2.0"       # 连续接触
    DAILY = "1.8"            # 每天几次接触
    WEEKLY = "1.6"           # 每周接触
    MONTHLY = "1.4"          # 每月接触
    YEARLY = "1.2"           # 每年接触
    RARE = "1.0"             # 很少接触
class ConsequenceTier(StrEnum):     # C 后果
    CATASTROPHE = "25"       # 灾难
    VERY_SEVERE = "22"       # 非常严重
    SEVERE = "20"            # 严重
    MODERATE = "18"          # 一般
    MINOR = "15"             # 轻微
class DifficultyTier(StrEnum):      # X 排查难度
    HARD = "1"               # 难
    FAIRLY_HARD = "0.99"     # 较难
    NORMAL = "0.98"          # 一般

TIER_LABEL_MAP: dict[str, dict[str, str]]   # 枚举→中文档位（"2.0"→"非常可能"…），全 17 档
LABEL_TO_TIER: dict[str, dict[str, str]]    # 反向映射（AI 输出中文→枚举）

class RiskBandEnum(StrEnum): HIGH="H"; MEDIUM="M"; LOW="L"

class HazardScoringInput(BaseModel):
    hazard_no: str | None
    description: str                      # 原始描述
    key_defect: str | None = None         # ①轮 AI 描述
    hazard_type: str | None               # EN 枚举码 unsafe_action/…
    hazard_category: str | None           # EN 枚举码 13 类
    hazard_level: str | None              # ①轮 AI 级别 general/serious/major
    major_hazard_basis: str | None        # ①轮判定依据原文
    department: str | None                # 整改责任部门（隐患位置语境）
    inspection_category: str | None       # 检查类别（语境，非参评判据——资格在 shortlist 算）
    # 注意：不含 discovered_by_name / 检查人员——评分输入天然匿名（制度 §10.3 匿名要求）

class MajorHazardHit(BaseModel):
    hit: bool = False
    clauses: list[str] = []               # 如 ["附件一·五", "AQ3067·生产运行"]

class HazardScoringOutput(BaseModel):
    likelihood: LikelihoodTier;  likelihood_reason: str    # 每维一句理由，≤60字
    exposure: ExposureTier;      exposure_reason: str
    consequence: ConsequenceTier; consequence_reason: str
    difficulty: DifficultyTier;  difficulty_reason: str
    band: RiskBandEnum;          band_basis: str           # 附件四/五条目引用，≤60字
    major_hazard: MajorHazardHit
    summary: str                           # ≤80字综合评语
    # 明确不含 total_score —— 代码计算
```

### 2.2 `rules.py`（纯函数，全部可单测）

| 函数 | 逻辑 |
|---|---|
| `compute_total(out) -> float` | `round(L×E×C×X, 1)`；理论区间断言 [14.7, 100] |
| `band_consistency(out, d) -> str \| None` | `(d>=45 and band==L)` 或 `(d<25 and band==H)` → 返回警示文案，否则 None |
| `validate_output(raw: dict) -> HazardScoringOutput` | 中文档位→枚举映射（`LABEL_TO_TIER`）；**任一档位→抛 `ScoringError`**（⑤轮语义=不写、下轮重试，与①轮「枚举校验丢弃」不同：评分无「部分可写」语义，四维必须齐全） |

### 2.3 `prompts.py`

结构（对标 `ai_hazard_identification/prompts.py`）：

- `SYSTEM_ROLE`：化工企业隐患风险评分专家；只依据给定档位表选择，禁止自创分值；输出 JSON。
- `LECX_TABLE`：制度 §10.3 四维档位表**全文**（17 档，上文 2.1 的中文标签即出自此表）。
- `MAJOR_CLAUSES_INDEX`：附件一 20 条 + AQ3067 六类（重点从业人员/设计与规划/工艺技术/设备设施/生产运行/作业安全/安全管理）**条目号级摘要**（每条 ≤30 字，供 AI 引用条目号，不塞全文）。
- `CATEGORY_BAND_TABLE`：13 类别 × 附件四/五典型条目对照（每类 ≤6 条，标注典型 H/M/L）——映射关系：

  | 系统类别(EN) | 附件对照源 | 典型条目（示例） |
  |---|---|---|
  | equipment | 附件四·设备管道缺陷 + 附件五·设备 | 淘汰设备H / 安全设施超期未校验H / 设备异响振动H / 探头失效M / 防护罩脱落M |
  | hazardous_storage | 附件四·7S + 附件五·危化 | 禁忌危化品混放H / 超量超品种M / 防腐防漏不符M |
  | emergency_mgmt | 附件四·维护保养 + 附件五 | 消防设施配置不足M / 灭火器缺维护M / 通道堵塞M |
  | instrument_electrical | 附件五·仪表/电气 + 附件四·用电 | 防爆失效H / 非防爆无控制H / 接地缺陷M |
  | lightning_antistatic | 附件四·静电释放/意外故障 | 无静电释放装置M / 跨接缺失L / 静电接地故障M |
  | occupational_health | 附件四·防护装置/照度 + 附件五 | 未佩戴PPE M / LEV未用M / 照度不足L |
  | violation_operation | 附件四·人的因素/违章指挥 | 惰性化不到位H / 试压试漏不到位H / 无证作业H |
  | six_s | 附件四·7S/滑倒 | 定置存放L / 地面湿滑L |
  | label_signage | 附件四·标志缺失 | 警示标志缺失M / 标签错误M / 提示缺失L |
  | process_mgmt | 附件五·安全操作/变更 | 擅改工艺H / 带压紧固H / 变更未评估H |
  | contractor_defect | 附件五·相关方 | 资质不符M / 三证不齐M |
  | documentation | 附件五·培训/风险管理/制度 | 未培训独立上岗H / JHA缺失M / 记录不齐M |
  | special_operation | 附件四·危险作业管理 | 特种作业措施不到位M / 开票原则错误H |

- `build_context_text(input)`：隐患编号/描述/AI描述/分类(中)/类别(中)/级别/判定依据/部门/检查类别。
- `build_full_prompt(context)`：context + LECX_TABLE + CATEGORY_BAND_TABLE + MAJOR_CLAUSES_INDEX + 输出契约 + 1 个 few-shot（禁抄分值，展示档位选择+条目引用格式）。
- `get_expected_keys()`: `["likelihood","likelihood_reason","exposure","exposure_reason","consequence","consequence_reason","difficulty","difficulty_reason","band","band_basis","major_hazard","quality","summary"]`。
- token 预算：SYSTEM+全部表+few-shot 静态部分 ≤ 2.5k tokens；输入 context ≤ 1.5k（描述截断 800 字）。
